# Архитектура формирования упражнений

## Обзор

Упражнения в 101slovo формируются **динамически** из слов пользователя, а не захардкожены. Это обеспечивает персонализированное обучение на основе:
- Уровня пользователя
- Выбранного словаря
- Алгоритма интервального повторения (SRS)
- Генерации предложений через LLM (GigaChat)

## Поток данных

```

│ 1. PREVIEW — Подбор слов                                        │
│    POST /lesson/preview                                         │
│    └─ Возвращает: due_words + new_words                         │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 2. ПОЛЬЗОВАТЕЛЬСКИЙ ВЫБОР                                       │
│    - Пользователь видит список слов                             │
│    - Может отказаться от новых слов (decline)                   │
│    - Подтверждает набор                                         │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 3. START — Старт урока                                          │
│    POST /lesson/start                                           │
│    Headers: Idempotency-Key                                     │

│    └─ Сервер:                                                   │
```

## Детали каждого этапа

### 1. Preview (Подбор слов)

**Эндпоинт:** `POST /lesson/preview`

**Алгоритм:**
1. Проверяет незавершённый урок (resume)
2. Проверяет дневной лимит
3. Находит **due-слова** — слова, у которых `due_lesson_number <= next_lesson_number`
4. Если due-слов меньше N, подбирает **новые слова**:
   - По уровню (текущий или на ступень ниже)
   - Из активного словаря
   - Исключая уже изученные
5. Детерминированно ранжирует через SHA-256 (одинаковый seed = одинаковый порядок)

**Возвращает:**
```json
{
  "state": "ready",
  "lesson_number": 5,
  "due_words": [
    { "word_id": 1, "lemma": "run", "pos": "verb" },
    { "word_id": 2, "lemma": "book", "pos": "noun" }
  ],
  "new_words": [
    { "word_id": 10, "lemma": "achieve", "pos": "verb", "translations": ["достигать"] },
    { "word_id": 11, "lemma": "goal", "pos": "noun", "translations": ["цель"] }
  ],
  "dictionary_exhausted": false
}
```

**Другие состояния:**
- `resume` — есть незавершённый урок
- `limit_reached` — дневной лимит исчерпан
- `no_words` — нет слов для изучения

### 2. Пользовательский выбор

Пользователь видит список слов и может:
- **Принять** все слова → переход к старту
- **Отказаться** от новых слов → `POST /lesson/new-word/decline`
  - Слово помечается как `ignored`
  - Preview пересчитывается
  - Пользователь видит обновлённый список

### 3. Start (Старт урока)

**Эндпоинт:** `POST /lesson/start`  
**Headers:** `Idempotency-Key: <uuid>`  
**Body:** `{ "word_ids": [1, 2, 10, 11] }`

**Алгоритм на сервере:**

#### a) Валидация и блокировки
- Проверка идемпотентности (повторный запрос = тот же урок)
- `pg_try_advisory_lock` для предотвращения параллельного старта
- Повторная проверка лимита и состава слов

#### b) Кластеризация слов
```python
# Алгоритм из utils/clustering.py
# Разбивает слова на группы по 1-3 слова
# Размеры групп отличаются не более чем на 1
# Меньшие группы идут первыми

# Пример для 5 слов:
# → [[word1, word2], [word3, word4, word5]]

# Пример для 7 слов:
# → [[w1, w2], [w3, w4], [w5, w6, w7]]
```

#### c) Генерация предложений через GigaChat
Для каждой группы вызывается Prompt 1:
```
Ты лингвист-методист. Для КАЖДОЙ группы слов составь 
ровно одно короткое предложение уровня {level}.

ПРАВИЛА:
- Предложение содержит ВСЕ слова своей группы
- Длина не более 15 слов
- Для каждого предложения дай перевод на русский
- Для каждого слова верни surface_form

Входные данные:
{
  "level": "A2",
  "groups": [
    { "group_index": 0, "words": [{"lemma": "run", "pos": "verb"}] }
  ]
}
```

#### d) Валидация ответа (10 правил)
1. sentence не пуста и ≤ 200 символов
2. reference_translation не пуста и ≤ 300 символов
3. sentence не содержит кириллицы
4. reference_translation содержит кириллицу
5. Предложения не дублируются
6. Множество (lemma, pos) равно запрошенному
7. surface_form найдена в предложении
8. Формы не пересекаются
9. surface_form не пуста
10. Все группы присутствуют в ответе

При ошибке — частичный повтор (только невалидные группы, до 2 раз).

#### e) Запись в БД
- Создаётся запись в `lessons`
- Для каждой группы — запись в `lesson_exercises` с JSONB `target_words`
- Новые слова добавляются в `user_words` со `status='active'`
- Обновляется `last_lesson_number` в профиле

**Возвращает:**
```json
{
  "lesson_id": 5,
  "lesson_number": 5,
  "exercises_total": 3,
  "created": true,
  "current_exercise": {
    "exercise_id": 15,
    "order_index": 1,
    "sentence": "She achieved her goal through hard work."
  }
}
```

### 4. Решение упражнений

#### Получение текущего упражнения
**Эндпоинт:** `GET /lesson/{id}/current`

**Возвращает:**
```json
{
  "lesson_id": 5,
  "exercises_done": 0,
  "exercises_total": 3,
  "current_exercise": {
    "exercise_id": 15,
    "order_index": 1,
    "sentence": "She achieved her goal through hard work."
  }
}
```

#### Проверка перевода
**Эндпоинт:** `POST /lesson/evaluate`  
**Body:**
```json
{
  "exercise_id": 15,
  "translation": "Она достигла своей цели благодаря упорному труду.",
  "dont_know": false
}
```

**Алгоритм:**
1. Вызывается Prompt 2 (оценка перевода) через GigaChat
2. GigaChat оценивает каждое целевое слово:
   - `correct` — правильный перевод
   - `typo` — верный перевод с опечаткой
   - `incorrect` — неверный перевод
3. Возвращает `user_fragment` — фрагмент перевода пользователя
4. Предлагает новые слова для изучения (до 3)

**Обновление SRS:**
```python
# Для каждого целевого слова:
if result in ('correct', 'typo'):
    new_stage = stage + 1  # до 6
else:
    new_stage = max(stage - 1, 0)

# Интервалы: [1, 2, 3, 7, 11, 30] уроков
due_lesson_number = current_lesson + INTERVALS[new_stage - 1]

# При stage=6 и correct → status='mastered'
```

**Возвращает:**
```json
{
  "exercise_id": 15,
  "target_sentence": "She achieved her goal through hard work.",
  "reference_translation": "Она достигла своей цели благодаря упорному труду.",
  "user_translation": "Она достигла своей цели благодаря упорному труду.",
  "words": [
    {
      "word_id": 10,
      "lemma": "achieve",
      "pos": "verb",
      "surface_form": "achieved",
      "result": "correct",
      "user_fragment": "достигла",
      "translations": ["достигать"]
    },
    {
      "word_id": 11,
      "lemma": "goal",
      "pos": "noun",
      "surface_form": "goal",
      "result": "correct",
      "user_fragment": "цели",
      "translations": ["цель"]
    }
  ],
  "suggestions": [
    {
      "word_id": 20,
      "lemma": "hard",
      "pos": "adj",
      "translations": ["усердный", "тяжёлый"],
      "state": "suggested"
    }
  ],
  "lesson_completed": false
}
```

#### Обработка подсказок
После оценки пользователь может:
- **Добавить** слово: `POST /lesson/exercises/{id}/suggestions/{word_id}` с `{"action": "add"}`
- **Игнорировать**: `{"action": "ignore"}`

#### Ветка "Не знаю"
**Body:** `{ "exercise_id": 15, "dont_know": true }`

- Все слова получают `result = 'incorrect'`
- LLM не вызывается
- SRS обновляется как при incorrect
- Показывается эталонный перевод

### 5. Завершение урока

Автоматически при последнем упражнении:
- `lessons.status` меняется на `'completed'`
- Устанавливается `completed_at` и `completed_local_date`
- Событие `lesson_completed`

Пользователь переходит на страницу итогов:
**Эндпоинт:** `GET /lesson/{id}/summary`

**Возвращает:**
```json
{
  "lesson_number": 5,
  "words_total": 8,
  "reviewed": 5,
  "new_words": 3,
  "correct": 6,
  "typo": 1,
  "incorrect": 1,
  "without_errors": 7,
  "suggestions_added": 2,
  "streak": {
    "current": 5,
    "longest": 10,
    "today_done": true,
    "extended_today": false
  }
}
```

## Обработка ошибок

### На этапе Preview
- `onboarding_required` (409) — пользователь не прошёл онбординг
- `limit_reached` — дневной лимит исчерпан
- `no_words` — нет слов для изучения

### На этапе Start
- `resume_available` (409) — есть незавершённый урок
- `preview_outdated` (409) — состав слов изменился
- `start_in_progress` (409) — параллельный старт
- `llm_unavailable` (503) — GigaChat недоступен
- `llm_invalid_response` (503) — LLM вернул невалидный ответ

### На этапе Evaluate
- `exercise_not_found` (404)
- `lesson_not_active` (409)
- `not_current_exercise` (409) — не то упражнение
- `invalid_input` (422) — невалидный перевод
- `llm_refused` (422) — GigaChat отказался обрабатывать

## Идемпотентность

- **Preview**: идемпотентен по природе (детерминированный)
- **Start**: через `Idempotency-Key` — повторный запрос возвращает существующий урок
- **Evaluate**: идемпотентен — повторный запрос возвращает сохранённый результат

## Rate Limiting

- Evaluate: 30 запросов/мин на пользователя
- Reports: 20 жалоб/час на пользователя

## События (events)

- `lesson_started` — старт урока
- `new_word_accepted` — принято новое слово
- `new_word_declined` — отказ от слова
- `exercise_evaluated` — оценка упражнения
- `lesson_completed` — завершение урока
- `report_sent` — жалоба на предложение

## Пример полного цикла

### Сценарий: Пользователь A2, словарь "general"

1. **Preview**:
   - due_words: `[run, book]` (пора повторить)
   - new_words: `[achieve, goal, improve]` (новые)
   - Всего: 5 слов

2. **Пользовательский выбор**:
   - Отказывается от `improve`
   - Остаётся: `[run, book, achieve, goal]` (4 слова)

3. **Start**:
   - Кластеризация: `[[run, book], [achieve, goal]]`
   - GigaChat генерирует:
     - "She runs to the book store."
     - "He achieved his goal through hard work."
   - Создаётся урок #5 с 2 упражнениями

4. **Решение**:
   - Упражнение 1: переводит "Она бежит в книжный магазин"
     - run → correct, book → correct
     - Подсказка: `store` (магазин)
   - Упражнение 2: переводит "Он достиг своей цели..."
     - achieve → correct, goal → typo (опечатка)
     - Подсказка: `hard` (усердный)

5. **Завершение**:
   - Урок завершён
   - SRS обновлён:
     - run: stage 2 → 3, due = lesson 5 + 3 = 8
     - book: stage 1 → 2, due = lesson 5 + 2 = 7
     - achieve: stage 0 → 1, due = lesson 5 + 1 = 6
     - goal: stage 0 → 1 (typo считается correct), due = 6
   - Стрик: +1 день
   - Summary: 4 слова, 3 correct, 1 typo, 0 incorrect

## Ключевые преимущества динамической генерации

1. **Персонализация** — предложения создаются из слов пользователя
2. **Контекст** — слова изучаются в естественных предложениях
3. **Разнообразие** — каждый урок уникален
4. **Качество** — LLM генерирует грамматически правильные предложения
5. **Адаптивность** — учитываются due-слова и уровень пользователя
