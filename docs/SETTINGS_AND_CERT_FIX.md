## 2. Исправлена ошибка сертификата GigaChat

### Проблема

При запуске урока возникала ошибка:
```
LLM generation failed: [Errno 2] No such file or directory
```

**Причина:** Файл сертификата `./certs/russian_trusted_root_ca_pem.crt` не существует.

### Решение

Добавлена обработка ошибки отсутствия файла сертификата:

**Было:**
```python
ssl_context = ssl.create_default_context(cafile=settings.GIGACHAT_CA_CERT_PATH)
```

**Стало:**
```python
try:
    ssl_context = ssl.create_default_context(cafile=settings.GIGACHAT_CA_CERT_PATH)
except FileNotFoundError:
    logger.warning(
        f"Сертификат GigaChat не найден: {settings.GIGACHAT_CA_CERT_PATH}. "
        "Используются системные сертификаты."
    )
    ssl_context = ssl.create_default_context()
```

### Файлы изменены

- `backend/app/services/llm/gigachat.py` - добавлена обработка FileNotFoundError в 2 местах:
  - Строка 80: при получении OAuth токена
  - Строка 270: при вызове API генерации предложений

### Как это работает

1. Пытается загрузить сертификат из `GIGACHAT_CA_CERT_PATH`
2. Если файл не найден:
   - Логирует предупреждение
   - Использует системные сертификаты (ssl.create_default_context() без параметров)
3. Продолжает работу нормально

### Преимущества

- ✅ Не требует обязательного наличия файла сертификата
- ✅ Использует системные сертификаты как fallback
- ✅ Логирует предупреждение для отладки
- ✅ Не прерывает работу приложения
