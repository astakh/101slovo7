## Как диагностировать

### Шаг 1: Перезапустите бэкенд

```bash
cd backend
uvicorn app.main:app --reload
```

### Шаг 2: Запустите урок через фронтенд

Откройте браузер и запустите урок.

### Шаг 3: Проверьте логи бэкенда

В терминале, где запущен бэкенд, вы увидите **полную картину**:

1. **Что отправляется в LLM:**
   - Промпт (system message)
   - Группы слов (user message)
   - Параметры (temperature, max_tokens)

2. **Что возвращает LLM:**
   - HTTP статус
   - Полный ответ (choices, content)
   - Finish reason

3. **Что извлекается:**
   - JSON из ответа
   - Структура данных

4. **Что валидируется:**
   - Каждая группа
   - Каждое поле (sentence, reference_translation, words)

### Шаг 4: Определите проблему

#### Если sentence пустое в ответе LLM:

```
📥 LLM RAW RESPONSE
Content (full):
[
  {
    "group_index": 0,
    "sentence": "",
    ...
  }
]
```

**Причина:** LLM не генерирует предложение  
**Решение:** Проверить промпт в БД

```bash
psql $DATABASE_URL -f sql/check_prompts.sql
```

#### Если ответ не JSON:

```
📥 LLM RAW RESPONSE
Content (full):
Вот предложения для ваших слов:
1. She runs every morning.
```

**Причина:** LLM не понимает, что нужно вернуть JSON  
**Решение:** Усилить промпт

```sql
UPDATE prompts 
SET system_template = '...Верни СТРОГО JSON без пояснений...'
WHERE key = 'generate_sentences';
```

#### Если ошибка парсинга JSON:

```
🔍 Extracting JSON from content...
❌ Failed to extract JSON: No JSON found in response
```

**Причина:** LLM возвращает текст без JSON  
**Решение:** 
1. Проверить промпт
2. Попробовать другую модель: `GIGACHAT_MODEL=GigaChat-2-Max`
3. Уменьшить температуру: `GEN_TEMPERATURE=0.3`

## Возможные решения

### 1. Проверить промпт в БД

```env

```

### 3. Уменьшить температуру

В `backend/.env`:
```env

```

