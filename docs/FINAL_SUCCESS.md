## Что было исправлено

### Проблема
LLM возвращал ответ в неправильном формате:
- ❌ Объект `{"sentences": [...]}` вместо массива
- ❌ Отсутствовало поле `sentence` (само предложение)
- ❌ Неправильное поле `surface_forms` вместо `words`
- ❌ Отсутствовали данные `word_id`, `lemma`, `pos`

### Решение

**1. Обновлён промпт в БД** (`sql/check_prompts.sql` и `scripts/update_prompt.py`):
- Добавлены явные инструкции: **"sentence" (ПОЛНОЕ предложение на английском языке!)**
- Добавлено: **"КРИТИЧЕСКИ ВАЖНО: Поле sentence ОБЯЗАТЕЛЬНО должно содержать ПОЛНОЕ предложение"**
- Обновлён пример с полным предложением

**2. Добавлен маппинг в `helpers.py`**:
- Автоматическое преобразование формата ответа LLM
- Если `sentence` отсутствует, генерирует из `surface_forms`
- Если `words` отсутствует, преобразует `surface_forms` в `words`

**3. Исправлена ошибка на фронтенде** (`Lesson.tsx`):
- Добавлена проверка на существование `target_words` перед вызовом `.map()`
- Обновлён интерфейс `Exercise` с опциональными полями

**4. Обновлён бэкенд** (`lesson_start.py`):
- Добавлены поля `lemma` и `pos` в `target_words_json`
- Возвращается полная информация о текущем упражнении:
  - `exercise_id`
  - `order_index`
  - `sentence`
  - `reference_translation`
  - `target_words`

## Как применить

### Шаг 1: Обновите промпт в БД

```bash
cd backend
python ../scripts/update_prompt.py
```

### Шаг 2: Перезапустите бэкенд

```bash
uvicorn app.main:app --reload
```

### Шаг 3: Запустите урок через фронтенд

1. Откройте http://localhost:5173
2. Войдите в аккаунт
3. Нажмите "Начать урок"
4. Выберите слова
5. Нажмите "Начать урок" снова

### Шаг 4: Проверьте результат

Должно отобразиться:
- Предложение на английском
- Целевые слова (выделены жёлтым)
- Поле для ввода перевода
- Кнопки "Не знаю" и "Проверить"

## Пример успешного урока

### Предложение
```
Bright light bites the eyes.
```

### Целевые слова
- Bright (bright, adj)
- bites (bite, verb)

### Перевод
```
Яркий свет режет глаза.
```

### Проверка
После ввода перевода и нажатия "Проверить":
- LLM оценивает перевод
- Показывает результат (correct/typo/incorrect)
- Предлагает новые слова
- Обновляет SRS
