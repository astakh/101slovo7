# Онбординг пользователя

## Описание

После регистрации пользователь проходит онбординг — процесс настройки профиля обучения. Онбординг состоит из 4 шагов:

1. **Выбор уровня английского** (A1, A2, B1, B2)
2. **Выбор словаря** (Общий, Бизнес, Путешествия, IT)
3. **Выбор часового пояса** (для корректного расчёта стрика)
4. **Подтверждение настроек**

## Как это работает

### 1. Пользователь регистрируется

После успешной регистрации пользователь автоматически перенаправляется на `/dashboard`.

### 2. Проверка статуса онбординга

На странице Dashboard проверяется поле `user.is_onboarded`:
- Если `false` — показывается баннер "Настройте профиль обучения" с кнопкой "Начать настройку"
- Если `true` — показывается обычный интерфейс с уроками

### 3. Прохождение онбординга

При нажатии на "Начать настройку" пользователь переходит на `/onboarding`.

#### Шаг 1: Выбор уровня

Пользователь выбирает один из 4 уровней:
- **A1** — Начальный (знакомые фразы, очень простые слова)
- **A2** — Элементарный (простые предложения, повседневные темы)
- **B1** — Средний (основные темы, выражение мнения)
- **B2** — Выше среднего (сложные тексты, абстрактные темы)

Каждый уровень содержит описание и примеры слов.

#### Шаг 2: Выбор часового пояса

Пользователь выбирает свой часовой пояс из списка российских часовых зон:
- Калининград (UTC+2)
- Москва (UTC+3)
- Самара (UTC+4)
- Екатеринбург (UTC+5)
- Омск (UTC+6)
- Красноярск (UTC+7)
- Иркутск (UTC+8)
- Якутск (UTC+9)
- Владивосток (UTC+10)
- Магадан (UTC+11)

#### Шаг 3: Подтверждение

Показываются выбранные настройки. Пользователь может вернуться и изменить их.

### 4. Завершение онбординга

При нажатии "Начать обучение":
1. Отправляется запрос на `POST /onboarding/complete` с данными `{ level, timezone }`
2. Обновляется поле `user.is_onboarded = true`
3. Пользователь перенаправляется на `/dashboard`
4. Баннер онбординга исчезает

## Навигация

- **Кнопка "Назад"** — возвращает на предыдущий шаг
- **Кнопка "Далее"** — переходит на следующий шаг (активна только если выбрано значение)
- **Кнопка "Начать обучение"** — завершает онбординг (на последнем шаге)

## Валидация

- Нельзя перейти на следующий шаг без выбора значения
- Кнопки "Далее" и "Начать обучение" блокируются, если не выбрано значение

## API интеграция

### Текущая реализация (заглушка)

Сейчас используется имитация API:
```typescript
await new Promise(resolve => setTimeout(resolve, 1000));
setUser({ ...user, is_onboarded: true });
```

### Подключение реального API

В `src/pages/Onboarding.tsx` замените заглушку на реальный вызов:

```typescript
const handleComplete = async () => {
  setIsLoading(true);
  try {
    const response = await fetch('http://localhost:8000/onboarding/complete', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`,
      },
      body: JSON.stringify({ level, timezone }),
    });

    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.detail || 'Ошибка онбординга');
    }

    // Обновляем статус пользователя
    if (user) {
      setUser({ ...user, is_onboarded: true });
    }

    navigate('/dashboard');
  } catch (error) {
    console.error('Ошибка онбординга:', error);
    // Показать ошибку пользователю
  } finally {
    setIsLoading(false);
  }
};
```

## Состояние

Компонент использует локальное состояние:
- `step` — текущий шаг (1, 2, 3)
- `level` — выбранный уровень (A1, A2, B1, B2)
- `timezone` — выбранный часовой пояс
- `isLoading` — состояние загрузки при завершении

## Анимации

Используются анимации из `framer-motion`:
- Плавный переход между шагами
- Анимация прогресс-бара
- Hover-эффекты на карточках уровней

## Тестирование

1. Зарегистрируйтесь
2. Вы попадёте на `/dashboard` с баннером онбординга
3. Нажмите "Начать настройку"
4. Выберите уровень (например, A2)
5. Нажмите "Далее"
6. Выберите часовой пояс (например, Москва)
7. Нажмите "Далее"
8. Проверьте настройки на последнем шаге
9. Нажмите "Начать обучение"
10. Вы вернётесь на `/dashboard` без баннера

## Ошибки и решения

### "Property 'setUser' does not exist"
Убедитесь, что `setUser` добавлен в `AuthContextType` и провайдер.

### Кнопка "Далее" неактивна
Проверьте, что выбрано значение на текущем шаге.

### Перенаправление не работает
Проверьте, что маршрут `/onboarding` добавлен в `App.tsx` и защищён `ProtectedRoute`.
