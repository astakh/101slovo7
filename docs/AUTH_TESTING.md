# Тестирование авторизации

## Как протестировать

### 1. Запустите frontend
```bash
npm run dev
```

### 2. Откройте http://localhost:5173

### 3. Тестирование регистрации
1. Нажмите кнопку **"Регистрация"** в шапке или **"Начать бесплатно"**
2. Заполните форму:
   - Email: любой (например, `test@example.com`)
   - Пароль: минимум 8 символов (например, `password123`)
   - Подтверждение пароля: должно совпадать
3. Нажмите **"Зарегистрироваться"**
4. Должно произойти:
   - Появится индикатор загрузки
   - Через 1 секунду модалка закроется
   - Произойдёт перенаправление на `/dashboard`
   - В шапке появится email пользователя и кнопка "Выйти"

### 4. Тестирование входа
1. Нажмите **"Выйти"** в шапке
2. Нажмите **"Войти"**
3. Введите те же данные:
   - Email: `test@example.com`
   - Пароль: `password123`
4. Нажмите **"Войти"**
5. Должно произойти перенаправление на `/dashboard`

### 5. Тестирование валидации
Попробуйте:
- Оставить поля пустыми → ошибка "Заполните все поля"
- Ввести пароль < 8 символов → ошибка "Пароль должен содержать минимум 8 символов"
- Ввести разные пароли при регистрации → ошибка "Пароли не совпадают"

### 6. Тестирование защищённых маршрутов
1. Выйдите из аккаунта
2. Попробуйте открыть http://localhost:5173/dashboard
3. Должно произойти перенаправление на главную страницу

## Проверка в консоли браузера

Откройте DevTools (F12) → Console:

При успешной регистрации/входе вы увидите:
```
✅ Успешная регистрация: test@example.com
```
или
```
✅ Успешный вход: test@example.com
```

При выходе:
```
✅ Выход выполнен
```

## Проверка localStorage

В DevTools → Application → Local Storage → http://localhost:5173

Должен быть ключ:
- `access_token` = `mock_token_{timestamp}`

## Что дальше?

Для подключения к реальному бэкенду:

1. Запустите backend:
```bash
cd backend
uvicorn app.main:app --reload
```

2. В `src/contexts/AuthContext.tsx` замените заглушки на реальные API вызовы (см. комментарии в коде)

3. Обновите URL API в `.env` frontend:
```env
VITE_API_URL=http://localhost:8000
```

## Ошибки и решения

### "Cannot find name 'useAuth'"
Убедитесь, что импортировали `useAuth` из `../contexts/AuthContext`

### "useAuth must be used within an AuthProvider"
Проверьте, что `AuthProvider` оборачивает приложение в `App.tsx`

### Перенаправление не работает
Проверьте, что установлен `react-router-dom`:
```bash
npm install react-router-dom
```

### Токен не сохраняется
Проверьте, что `localStorage` доступен (не в режиме инкогнито с ограничениями)
